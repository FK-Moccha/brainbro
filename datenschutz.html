3. Werkzeug „BrainBro Upload“

„BrainBro Upload“ ist ein internes Programm, das ausschließlich vom Betreiber auf dessen eigenem Computer genutzt wird, um eigene Videos auf den eigenen Konten von @DerBrainBro zu veröffentlichen.

  • Genutzte Schnittstellen: YouTube Data API (Google), Instagram API (Meta), TikTok Content Posting API (TikTok).
  • Verarbeitete Daten: nur die Zugangs-Token der eigenen Konten sowie die eigenen Videos, Titel, Beschreibungen und Titelbilder. Es werden keine Daten anderer Nutzer abgerufen, gespeichert oder weitergegeben.
  • Speicherort: Zugangs-Token liegen nur lokal auf dem Computer des Betreibers. Titelbilder werden für wenige Sekunden bei Cloudinary zwischengespeichert, damit Instagram sie abrufen kann, und danach gelöscht.
  • Widerruf: Der Zugriff kann jederzeit in den Konto-Einstellungen von Google (myaccount.google.com/permissions), Instagram und TikTok entzogen werden.

Die Nutzung der YouTube-Schnittstelle unterliegt den YouTube-Nutzungsbedingungen und der Datenschutzerklärung von Google.
